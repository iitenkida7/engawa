# カメラ仮想背景の画像プリセット (#233)

このフォルダに画像ファイルを置くと、**自動でカメラ背景のプリセットとして選べる**ようになります（コード変更不要）。

## 使い方
- 対応形式: `.jpg` / `.jpeg` / `.png` / `.webp`
- ファイル名がそのままプリセット名になります（`-` / `_` は空白に、各単語の先頭を大文字化）。
  - 例: `aoyama-cafe.jpg` → メニュー表示「Aoyama Cafe」
- 横長（16:9 程度）・長辺 1280〜1920px 推奨。カメラ映像に cover-fit で描画されます。

## ライセンス（重要）
engawa の素材方針（CLAUDE.md）に従い、**CC0 など再配布可能なライセンスの画像のみ**を置いてください。
- 出典・作者・ライセンスを `CREDITS.md`（このフォルダ）に記録してください。
- CC0 以外（CC-BY など）を使う場合は帰属表示の要件も満たすこと。

## 仕組み
`media/vbg.ts` の `imagePresets()` が Vite の `import.meta.glob` でこのフォルダを走査し、
見つかった画像を `bg:<ファイル名>` という id のプリセットとして登録します。
