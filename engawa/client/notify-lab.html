🔔 デスクトップ通知ラボ

Notification API を単体で叩いて、OS 通知が出るかを切り分ける。engawa 本体のノック判定（knockAlertLevel）が今の状態で何を返すかも表示する。

環境

送信

⚙️ macOS の通知設定を開く Chrome のサイト設定は chrome://settings/content/notifications（ページからは開けないのでアドレスバーに貼る）

イベントログ


    

    
    
      
  • 「遅延して〜」は押したあと別ウィンドウ/別アプリに切り替えて、裏にいる状態で届くかを確かめる用。
    • 
      
  • 「疑似ノック」は本体と同じ DesktopNotifier.knock() を、その瞬間の knockAlertLevel()（status=online）で呼ぶ。
    • 
      
  • show イベントが出ているのに画面に出ない → OS 側（macOS: システム設定 › 通知 › Google Chrome の許可 / 集中モード）で止まっている可能性が高い。
    • 
      
  • error / 例外が出る → ブラウザ側（サイト権限・非セキュアコンテキスト・Service Worker 必須環境）の問題。
